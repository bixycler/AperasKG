Design docs, dev status, and reports for the Aperas project, tracked as `ArtifactNode`/`FolderNode`
content in ApeironNgn's own knowledge graph (`Aperas-apeironngn-design.md`) — this tree is both
documentation and a live corpus the substrate ingests itself.

- `Aperas-apeironngn-design.md` — the current engine: storage encoding, id/IRI scheme, query model.
- `Aperas-treeview-design.md` — the i-projection layer: `TreeView`/`Profile`, fold state, Viewcone Zoom.
- `Aperas-dev-status.md` — stale as of the ApeironNgn migration; not yet updated to match.
- `archive/` — superseded designs, kept for history rather than deleted.
- `reports/` — working notes and bug reports, separate from the design docs above.
